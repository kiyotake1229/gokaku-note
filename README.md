# 合格ノート

資格の合格をめざすための、スマホ向け学習アプリ（PWA）です。

- 教科書（資格ごと・分野ごとに、1回3〜5分で読める短いレッスン。読んだら確認問題で理解を確かめる）
- 練習問題・模擬試験（本番に近い問題数と時間）
- 公式の過去問（IPA 公開問題：ITパスポート 令和8・7年度、情報セキュリティマネジメント 令和8年度）。本番形式（時間つき）でも解ける
- 2027年度からの新しい試験の範囲の問題（IPA のシラバス案にもとづく）
- 分野ごとの要点まとめ
- 計算ドリル（2進数・稼働率・損益分岐点・境界値分析・広告の指標など。数字を変えて何度でも出る）
- 間違えた問題の復習（忘れかけた頃にもう一度出る間隔反復）
- 用語カード（読み上げ・聞き流しつき）
- 問題・解説・用語の検索
- 受験日から逆算した1日の目安と、遅れのお知らせ
- カレンダーへの登録（毎日の勉強の時間・受験日・申込みの締切。.ics ファイルと Google カレンダー）
- 「この問題、おかしい？」の報告（まとめて送れる。次の内容チェックで優先して確かめる）
- 学習ログ・問題の結果・受験の予定と結果（Excel へのコピー、CSV 書き出し）、バックアップ（共有メニューから保存・お知らせつき）
- 30分の学習タイマー、文字の大きさの設定
- 相談相手への進み具合レポート（リンクを送るだけで、資格ごとの状況・学習時間・「聞きたいこと」を見てもらえる。相談相手はレポートの画面から答えを書いて返信でき、返信のリンクを開くと学習ログに取り込める）
- 自動で共有（任意）：自分の Google スプレッドシートに記録を送り、相談相手がいつでも最新の進み具合を見られる。バックアップにもなる

収録している資格：LINE公式アカウント Basic／Advanced、GA4認定資格、Google広告認定資格（検索広告）、JSTQB Foundation Level、生成AIパスポート、ITパスポート、情報セキュリティマネジメント

## 使い方

スマホのブラウザで公開ページを開き、「ホーム画面に追加」するとアプリとして使えます。記録は端末の中（ブラウザの保存領域）にだけ保存されます。

## 進み具合レポートのしくみ

記録は端末の中にだけあり、サーバーは使いません。レポートと返信の中身は、リンクの `#` より後ろ（圧縮して文字にしたもの）に入っています。`#` より後ろはサーバーに送られないので、GitHub には記録が残りません。リンクを知っている人は見られるので、相談相手にだけ送ってください。

「自動で共有」を使うときだけ、記録が学習者自身の Google スプレッドシート（自分で公開した Apps Script：`tools/gas/Code.gs`）に送られます。読み書きには、アプリが作った鍵が必要です。

## ご注意

- 練習問題はこのアプリのために作ったオリジナルです。ただし「公式の過去問」は、IPA（独立行政法人 情報処理推進機構）が公開している試験問題を、出典を示して収録しています（解説はこのアプリが作成）。
- 「2027年からの新しい範囲」の問題は、IPA のシラバス案（Ver.0.1）をもとに作りました。シラバスが確定すると、内容が変わることがあります。
- 試験の情報は公式ページで確認したものです。申込みの前に、必ず公式ページを確認してください。

## 開発メモ

ビルドは不要です（素の JavaScript）。データの作り直しは `tools/` のスクリプトで行います。

- `tools/extract_guides.py`：学習ガイドのHTMLから `data/guides/*.json` を作る
- `tools/build_data.py`：問題作成ワークフローの記録から `data/questions`・`data/terms` を作る（`data/extra/` の問題も数に入れる）
- `tools/build_extra.py`：公開問題・新しい範囲・要点まとめの成果物から `data/extra/`・`data/summaries/` を作る
- `tools/build_lessons.py`：教科書の成果物から `data/lessons/` を作る
- `tools/flagged.py`：アプリで報告された問題を、いまのデータと並べて表示する
- `tools/gen_sw.py`：オフライン用の `sw.js` を作る（データを変えたら必ず実行）
- `tools/devserver.py`：確認用のサーバー（自動共有の確認用に、Apps Script のまねも入っている）
