# 合格ノート

資格の合格をめざすための、スマホ向け学習アプリ（PWA）です。

- 練習問題・模擬試験（本番に近い問題数と時間）
- 間違えた問題の復習（忘れかけた頃にもう一度出る間隔反復）
- 用語カード
- 学習ログ・問題の結果・受験の予定と結果（Excel へのコピー、CSV 書き出し）
- 30分の学習タイマー
- 相談相手への進み具合レポート（リンクを送るだけで、資格ごとの状況・学習時間・「聞きたいこと」を見てもらえる。相談相手はレポートの画面から答えを書いて返信でき、返信のリンクを開くと学習ログに取り込める）

収録している資格：LINE公式アカウント Basic／Advanced、GA4認定資格、Google広告認定資格（検索広告）、JSTQB Foundation Level、生成AIパスポート、ITパスポート、情報セキュリティマネジメント

## 使い方

スマホのブラウザで公開ページを開き、「ホーム画面に追加」するとアプリとして使えます。記録は端末の中（ブラウザの保存領域）にだけ保存されます。

## 進み具合レポートのしくみ

記録は端末の中にだけあり、サーバーは使いません。レポートと返信の中身は、リンクの `#` より後ろ（圧縮して文字にしたもの）に入っています。`#` より後ろはサーバーに送られないので、GitHub には記録が残りません。リンクを知っている人は見られるので、相談相手にだけ送ってください。

## ご注意

- 練習問題はこのアプリのために作ったオリジナルです。実際の試験問題ではありません。
- 試験の情報は 2026年9月20日時点で公式ページを確認したものです。申込みの前に、必ず公式ページを確認してください。

## 開発メモ

ビルドは不要です（素の JavaScript）。データの作り直しは `tools/` のスクリプトで行います。

- `tools/extract_guides.py`：学習ガイドのHTMLから `data/guides/*.json` を作る
- `tools/build_data.py`：問題作成ワークフローの記録から `data/questions`・`data/terms` を作る
- `tools/gen_sw.py`：オフライン用の `sw.js` を作る（データを変えたら必ず実行）
- `tools/devserver.py`：確認用のサーバー
